登录内网服务

输入 内网 IP : 端口（可带子路径），登录后所有请求代理到该地址

支持 http / https / WebSocket，省略协议默认 http；自签 https 证书自动忽略校验。
服务挂在子路径时把路径一起填上，例如 10.0.0.5:9000/wangzhang/；静态资源若在别的目录，网关会自动探测。
页面空白时优先用「透明代理」；它不改写任何 HTML/JS，可从根上避免改写导致的故障。
备注会显示在右侧列表，方便区分多个相似地址。
